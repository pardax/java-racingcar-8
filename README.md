# java-racingcar-precourse

### 기능 구현 목록
- [o] 문자열을 입력받고, split함수를 통해 이름들의 배열을 초기화한다.
- [o] 사용자가 5자를 초과한 이름을 입력할 경우 IllegalArgumentException 출력.
- [o] RacingCar 클래스를 따로만들어 독립적인 값을 갖도록 한다.
- [o] RacingCar 클래스에서 앞으로 한칸 전진하는 함수 만들기
- [o] RacingCar 클래스에서 현재 자신의 상태를 문자로 출력하는 함수 만들기, 출력형식은 '이름 : 진행도' 포맷을 사용한다.
- [o] while루프를 통해 각 RancingCar마다 우승자가 나올때 까지 전진함수를 실행
- [o] 우승자는 1명이상이 나올 수 있고, 해당 우승자들을 출력하고 프로그램 종료
